# MML30: 30-day MML learning plan

Live site: https://inayarhmns.github.io/PRML/

## Daily use

```sh
bin/study          # start the local helper and open the app in Microsoft Edge
bin/study app      # once: install ~/Applications/MML30.app (Dock shortcut)
bin/study login    # when Overleaf downloads say the session expired
```

On each day page:

1. Do the tasks. Write math and D2L answers in Overleaf under `\section{Day N}`, Python work in `notebooks/dayNN.ipynb`, and LeetCode problems on leetcode.com.
2. **Download Overleaf PDF** deletes `docs/overleaf/`, then downloads the source and the compiled PDF again.
3. **Evaluate** runs Claude Code headless (`claude -p`), which grades your answers against the answer keys and appends your mistakes to Error Checks. Each run costs roughly $1.
4. **Finish & push** unlocks once today's Overleaf download is done. It commits everything and pushes to GitHub.

The reminder email (`.github/workflows/reminder.yml`) goes out at 17:00 WIB on weekdays and 06:00 WIB on weekends. It covers the day after your last finished day, and it skips any day on which you have already finished one.

## Layout

| Path | What |
|---|---|
| `docs/` | The site (GitHub Pages, `main` branch, `/docs` folder) |
| `docs/data/plan.json` | Generated by `scripts/build_plan.py` from the Notion plan |
| `docs/data/progress.json`, `errors.json`, `evaluations/` | Written by the helper |
| `docs/overleaf/` | Latest Overleaf source + PDF |
| `helper/server.py` | Local helper on `127.0.0.1:8765` (Python standard library only) |
| `scripts/send_reminder.py` | Email reminder (`DRY_RUN=1` writes a preview) |

Book links open your iCloud PDFs (`~/Library/Mobile Documents/com~apple~CloudDocs/MML`) at the exact page while the helper is running. When it isn't, they fall back to the free online editions.
